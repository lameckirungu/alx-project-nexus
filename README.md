# ALX Project Nexus

This Project is a GitHub repository dedicated to documenting major learnings from the ProDev Backend Engineering program. This repository serves as a knowledge hub, showcasing understanding of backend engineering concepts, tools, and best practices acquired throughout the program.

## Pedagogy

The program emphasizes practical application, with real-world projects that help you develop the skills required to build scalable systems and backend solutions. This hands-on approach ensures you gain valuable experience and create a portfolio that showcases your job-ready expertise.

## Tools Learners use

`Python`, `Javascript`, `MySQL`, `Docker`, `Kubernetes`, `Github Actions`, `Jenkins` and `GraphQL`.

### Content Breakdown

#### Part 01

Project Planning and Database Design

- Advanced SQL querying
- Advanced Python: Generators, decorators, context managers, and asynchrounous programming
- Testing: Unit, Integration tests using `pytest`.

#### Part 02

Advanced Shell commands and DevOps introduction

- CI/CD Pipelines: Setting up CI/CD using tools like Jenkins, or Github Actions.
- Containerization: Introduction to Docker and container orchestration with Kubernetes.
- Microservices: Designing and implementing a microservices architecture

- Message Queues: Using RabbitMQ or Kafka for asynchronous communication.

#### Part 03

Security and Performance Optimization

- Security Best Practices: SQL injection, CSRF, XSS, and Securing APIs
- Authentication and Authorization: JWT, Outh, and Django's built-in auth system
- Crons: Scheduling and automating tasks using cron jobs
- Caching: Strategies and tools like Redis or Memcache fro improving performance.

#### Part 04

- Bug Reporting Tools: Integrating tools like SEntry or Bugzilla for monitoring and reporting bugs.
- Network Traffic Analysis: Deep dive into traffic analysis using advanced tools and techniques.
